# 🍪 Cookie Clicker Auto-Clicker (Yandex Games)

Автоматический кликер для игры **Cookie Clicker**, запущенной на платформе Яндекс Игры. Скрипт использует компьютерное зрение (нейросеть YOLO от Ultralytics) для обнаружения большой печеньки на экране и автоматического клика по ней.

## 🚀 Особенности (Current Features)
* **Поиск объекта в реальном времени:** Скрипт анализирует экран с помощью библиотеки `mss` и находит точные координаты печеньки через модель YOLO.
* **Автоматический клик:** Самостоятельно нажимает на печеньку с высокой скоростью.
* **Современный стек:** Проект управляется с помощью быстрого пакетного менеджера `uv`.

## 🛠 Технологический стек
* Python
* Ultralytics YOLO (Computer Vision)
* MSS (Высокоскоростной захват экрана)
* `uv` (Пакетный менеджер)

## 📦 Установка и запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   gh repo clone sergey362727/peckenkaV10
   cd peckenkaV10
   ```

2. **Установите зависимости и создайте виртуальное окружение:**
   ```bash
   uv sync
   ```

3. **Запуск скрипта:**
   * Откройте браузер с игрой Cookie Clicker на Яндекс Играх.
   * Запустите автокликер командой:
   ```bash
   uv run .\app.py
   ```

## ⚠️ Известные ограничения и планы по доработке (Roadmap)
На данный момент бот находится в стадии активной разработки (v1.0) и имеет следующие ограничения, которые планируется исправить в будущих версиях:
- [ ] **Закрытие рекламы:** Бот пока не умеет определять появление рекламных блоков и закрывать их (из-за чего они могут перекрывать интерфейс).
- [ ] **Покупка улучшений:** Скрипт не кликает по магазину справа (не покупает Курсоры, Бабуль и другие апгрейды для автоматизации пассивного дохода).
